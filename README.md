# JScanner — اسکنر اسناد (Document Scanner)

برنامه‌ی رومیزی ویندوز برای اسکن و بایگانی اسناد هویتی (کارت ملی، شناسنامه و سایر مدارک) بر اساس کد ملی افراد. این برنامه با PyQt5 نوشته شده و از اسکنرهای سازگار با WIA در ویندوز پشتیبانی می‌کند.

## امکانات

- اسکن اسناد و ذخیره‌ی خودکار در پوشه‌ای مجزا بر اساس **کد ملی** هر فرد
- انتخاب نوع سند: روی کارت ملی، پشت کارت ملی، شناسنامه (صفحات ۱ تا ۵)، یا سایر (با عنوان دلخواه)
- سه سطح کیفیت اسکن: فشرده (۱۵۰dpi)، متعادل (۲۰۰dpi، پیشنهادی)، کیفیت بالا (۳۰۰dpi)
- انتخاب دستگاه اسکنر از میان اسکنرهای متصل به سیستم
- رابط کاربری فارسی

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- یک اسکنر سازگار با WIA (برای استفاده‌ی واقعی از اسکن؛ برای اجرای برنامه نیازی نیست)
- برای **ساخت** فایل exe از سورس: اتصال اینترنت (برای نصب پایتون و پکیج‌ها در اولین اجرا)

## نصب و اجرا 

### فایل‌های لازم
مطمئن شو این فایل‌ها همه در یک پوشه کنار هم هستن:
- `JScanner.py`
- `requirements.txt`
- `icon.ico`
- `install_JScanner.bat`

### مراحل
1. روی `install_JScanner.bat` دو بار کلیک کن.
2. یک پنجره‌ی User Account Control (UAC) باز می‌شه — روی **بله** بزن (این برای نصب پایتون در صورت نیاز لازمه).
3. اسکریپت به‌صورت کاملاً خودکار مراحل زیر رو انجام می‌ده:
   - بررسی نصب بودن پایتون؛ در صورت نبودن، نصب خودکار آن (از طریق winget یا دانلود مستقیم از python.org)
   - ساخت یک محیط مجازی ایزوله (`.venv`) مخصوص این پروژه
   - نصب پکیج‌های لازم (`requirements.txt`) داخل همان محیط مجازی
   - ساخت نسخه‌ی اجرایی با PyInstaller
   - ساخت شورت‌کات روی Desktop و در Start Menu
4. در پایان، پیام `Done!` نمایش داده می‌شه و برنامه در پوشه‌ی `dist\JScanner` آماده‌ی استفاده است.

> نیازی به نصب دستی پایتون یا pip نیست؛ همه‌چیز به‌صورت خودکار انجام می‌شه. فقط اتصال اینترنت لازمه.

### توزیع برنامه‌ی ساخته‌شده
اگه می‌خوای برنامه رو روی سیستم دیگه‌ای اجرا کنی، **کل پوشه‌ی `dist\JScanner`** رو کپی یا zip کن — نه فقط فایل `JScanner.exe`، چون فایل‌های کنارش برای اجرا لازم هستن.

## حذف کامل (Uninstall)

برای حذف کامل برنامه و تمام موارد نصب‌شده توسط اسکریپت build:

1. `uninstall_JScanner.bat` رو اجرا کن.
2. تاییدیه (Y) رو وارد کن.

این اسکریپت موارد زیر رو حذف می‌کنه:
- شورت‌کات‌های Desktop و Start Menu
- پوشه‌ی `dist\JScanner` (نسخه‌ی ساخته‌شده)
- پوشه‌ی `build` و فایل `JScanner.spec` (فایل‌های موقت PyInstaller)
- پوشه‌ی `.venv` — که تمام پکیج‌های پایتون نصب‌شده برای این پروژه (PyQt5، opencv-python، numpy، Pillow، pywin32، pyinstaller) رو هم به‌طور کامل و تمیز حذف می‌کنه

**چیزهایی که حذف نمی‌شن:**
- خود پایتون (چون ممکنه برنامه‌های دیگه‌ای روی سیستم بهش نیاز داشته باشن)
- فایل‌های سورس پروژه (`JScanner.py`, `requirements.txt`, `icon.ico`)

## ساختار پوشه‌ها بعد از اسکن

اسناد اسکن‌شده به این شکل بایگانی می‌شن:

```
<پوشه‌ی ذخیره‌سازی انتخابی>/
└── <کد ملی>/
    ├── <نوع سند 1>.jpg
    ├── <نوع سند 2>.jpg
    └── ...
```

هر فرد یک پوشه‌ی مجزا بر اساس کد ملی خودش داره و تمام مدارکش داخل همون پوشه ذخیره می‌شه.

## عیب‌یابی (Troubleshooting)

| مشکل | راه‌حل |
|---|---|
| خطای `'pip' is not recognized` یا `'pyinstaller' is not recognized` | این یعنی build مستقیم بدون اسکریپت اجرا شده؛ به‌جاش `build_exe_onedir.bat` رو اجرا کن که پایتون و پکیج‌ها رو خودش نصب می‌کنه |
| نصب پایتون با خطای `exit code 5` متوقف می‌شه | یعنی اسکریپت بدون دسترسی Administrator اجرا شده؛ مطمئن شو در پنجره‌ی UAC گزینه‌ی «بله» رو زدی |
| اسکنر در لیست دیده نمی‌شه | مطمئن شو درایور اسکنر نصب و دستگاه با WIA سازگاره؛ کابل و اتصال رو چک کن |
| برنامه بعد از کپی به سیستم دیگه اجرا نمی‌شه | کل پوشه‌ی `dist\JScanner` رو کپی کن، نه فقط فایل exe |
